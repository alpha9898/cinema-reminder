# 🎬 بوت أفلام السينما المصرية

بوت تيليجرام بيشيك على مواقع السينمات في مصر كل ساعة. أول ما فيلم جديد ينزل السينما، بيبعتلك:

- **البوستر** واسم الفيلم وتاريخ نزوله
- **المواعيد** في سينمات القاهرة والجيزة لأول يومين متاحين، مقسمة حسب السلسلة
- **اسم الموقع ولينك الفيلم** عليه

## المواقع

| الموقع | بيجيب منه إيه |
|---|---|
| **elCinema.com** | كل الأفلام المعروضة في مصر، ومواعيد كل السينمات (ومنه مواعيد **VOX** و **Premiere**) |
| **Scene / Galaxy** (`cfc.scenecinemas.com`, `district5.scenecinemas.com`, `moa.galaxy-cinema.com`) | الأفلام والمواعيد من موقع كل فرع |
| **Premiere Cinemas** | الأفلام اللي نزلت فعلاً، وأيام العرض، واللينك والبوستر |
| **VOX Cinemas** | قسم لوحده في الرسالة، ومواعيده من elCinema ومعاه لينك موقع VOX |

> موقع VOX مصر بيمنع أي برنامج آلي إنه يقراه، والمواعيد على موقع Premiere محتاجة تسجيل دخول. عشان كده مواعيد السلسلتين بتيجي من elCinema، وهو بيعرض سينمات VOX و Premiere كلها.

### إمتى بيبعت
- **فيلم جديد خالص**: صورة البوستر، وبعدها رسالة بالمواعيد.
- **فيلم اتبعت قبل كده وظهر على موقع تاني**: رسالة قصيرة "نزل كمان على ...".
- **أول تشغيل**: بيسجل الأفلام المعروضة دلوقتي من غير ما يبعتها، ويبعتلك رسالة واحدة إن البوت شغال.
- **لو موقع وقع**: بيبعت تحذير مرة واحدة، ويكمل بالباقي، ويقولك لما الموقع يرجع.

## الإعداد

### 1) اعمل البوت على تيليجرام
1. افتح [@BotFather](https://t.me/BotFather) وابعت `/newbot`، واختار اسم للبوت.
2. هياخد منك التوكن (شكله `123456:ABC...`). **متشاركوش مع حد.**
3. افتح البوت الجديد وابعتله `/start`.

### 2) جرّبه على جهازك
```bash
python3 -m venv .venv
```
```bash
.venv/bin/pip install -r requirements.txt
```
```bash
cp .env.example .env
```
حط التوكن في `.env` (`TELEGRAM_BOT_TOKEN=...`)، وبعدين:
```bash
.venv/bin/python get_chat_id.py
```
انسخ السطر `TELEGRAM_CHAT_ID=...` اللي هيطلع وحطه في `.env`.

تجربة من غير ما يبعت حاجة (بيطبع الرسايل بس):
```bash
.venv/bin/python -m cinema_bot.main --dry-run
```
تجربة حقيقية (هيبعتلك رسالة "البوت شغال"):
```bash
.venv/bin/python -m cinema_bot.main
```

### 3) شغّله على GitHub Actions (كل ساعة، ببلاش)
1. اعمل repo جديد على GitHub وارفع الفولدر ده عليه. ملف `.env` مش هيترفع لأنه في `.gitignore`.
2. في الـ repo روح على **Settings ← Secrets and variables ← Actions ← New repository secret** وضيف:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. روح على تاب **Actions ← Check cinemas ← Run workflow** عشان تشغله أول مرة بإيدك.
4. بعد كده هيشتغل لوحده كل ساعة، ويحفظ اللي شافه في `data/state.json`.

> **ريبو عام ولا خاص؟** الاتنين ينفعوا. التوكن متخزن في Secrets ومش بيظهر في الكود. الريبو الخاص ليه 2000 دقيقة مجانية في الشهر، والتشغيل الواحد بياخد دقيقة تقريباً، يعني حوالي 720 دقيقة في الشهر.

## الإعدادات (`config.yaml`)
- `cities`: المدن اللي تظهر مواعيد سينماتها (زي ما elCinema كاتبها: `Cairo`, `Giza`).
- `days_to_show`: كام يوم مواعيد يظهروا في الرسالة.
- `scene_branches`: فروع Scene / Galaxy.
- `chains`: السلاسل اللي ليها قسم لوحدها في الرسالة، وبتتعرف من كلمة في اسم السينما.

## أوامر مفيدة
| الأمر | بيعمل إيه |
|---|---|
| `python -m cinema_bot.main --dry-run` | يطبع الرسايل بدل ما يبعتها، ومش بيحفظ حاجة |
| `python -m cinema_bot.main --source elcinema` | يشغل موقع واحد بس |
| `python -m cinema_bot.main --send-existing` | في أول تشغيل: يبعت كل الأفلام المعروضة دلوقتي |
| `python -m pytest` | يشغل الاختبارات |

عايز البوت يبعت فيلم معين تاني؟ امسحه من `data/state.json` (من جوه `announced`).

## الملفات
```
cinema_bot/
  main.py          # بيجمع، يقارن، يبعت، ويحفظ
  sources/         # elcinema.py, scene.py, premiere.py
  message.py       # شكل الرسايل
  normalize.py     # يعرف إن "EBENZER" و "Ebenezer" نفس الفيلم
  telegram.py      # الإرسال لتيليجرام
  state.py         # data/state.json
tests/             # اختبارات على صفحات محفوظة من المواقع
```

لو موقع غيّر شكله، الاختبارات ممكن تفضل ناجحة (لأنها شغالة على صفحات محفوظة) لكن البوت هيبعتلك تحذير إن الموقع مش بيتقري. ساعتها لازم نعدل الـ parser بتاعه في `cinema_bot/sources/`.
